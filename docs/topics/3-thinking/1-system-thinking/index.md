# Systems thinking

## Definition

Arnold & Wade (2015) define systems thinking as:

> Systems thinking is a set of synergistic analytic skills used to improve the capability of identifying and understanding systems, predicting their behaviors, and devising modifications to them in order to produce desired effects. These skills work together as a system. (Arnold & Wade, 2015, p. 675)

## Skills

Arnold & Wade (2015, pp. 676--677) identify the following systems thinking skills:

**Recognizing Interconnections**:
Recognizing that elements of a system influence each other.

**Identifying and Understanding Feedback**:
Identifying and understanding cause-and-effect chains that influence themselves.

**Understanding System Structure**:
Understanding how elements and connections are structured in a system.

**Differentiating Types of Stocks, Flows, Variables**:
Differentiating between stocks (what accumulates), flows (what changes stocks) and other variables.

**Identifying and Understanding Non-Linear Relationships**:
Identifying and understanding non-linear stock and flows in a system.

**Understanding Dynamic Behavior**:
Understanding the dynamic behavior that emerges from interconnections, flows, stocks and feedback loops.

**Reducing Complexity by Modeling Systems Conceptually**:
Simplifying a system by modeling it conceptually.

**Understanding Systems at Different Scales**:
Understanding a system by different levels, such as system of systems.
