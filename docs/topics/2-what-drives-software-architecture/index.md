# What drives software architecture?

Software architecture and its decisions are driven by:

- Quality attributes (Bass et al., 2021, p. 39; Cervantes & Kazman, 2016, pp. 19--21)
- Functional requirements (Bass et al., 2021, p. 39; Cervantes & Kazman, 2016, pp. 25--26)
- Constraints (Cervantes & Kazman, 2016, pp. 27--28)
