# Layered architecture

## Definition

Bass et al. (2021, p. 128) describe the layers pattern as dividing the software into layers. Each layer is a unit of grouped modules. Each layer offers a cohesive set of services. A layer has a public interface. The allowed-to-use relation between layers has constraints. This allowed-to-use relation between layers must be unidirectional.

## Sources

Bass, L., Clements, P., & Kazman, R. (2021). *Software architecture in practice* (4th ed.). Addison-Wesley.
