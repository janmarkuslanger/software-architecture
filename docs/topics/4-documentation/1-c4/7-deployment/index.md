# Deployment Diagram

## What

A deployment diagram is a "way to diagram the deployment topology" (Brown, 2026, Chapter 8) for a software system.

## Audience

Engineers and software architects (Brown, 2026, Chapter 8, "Audience" section).

## Content

The content of a deployment diagram should be the internal container instances, software system instances outside of the current software system, deployment nodes as a building block of infrastructure, and infrastructure nodes which are items and services that are used in the environment (Brown, 2026, Chapter 8, "Content" section).

### Container instances

The container instances inside the software system (Brown, 2026, Chapter 8, "Container instances" section).

### Software system instances

Software system instances running outside of the current scope of the software system that interact with the current software system (Brown, 2026, Chapter 8, "Software system diagram" section).

### Deployment nodes

A building block of infrastructure where a container is running (Brown, 2026, Chapter 8, "Deployment nodes" section).

### Infrastructure nodes

An infrastructure node is a building block of infrastructure such as a load balancer or gateway (Brown, 2026, Chapter 8, "Infrastructure nodes" section).
