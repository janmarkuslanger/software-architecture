# Contributing

Thank you for contributing to this project. This is an evidence-based guide, so the rules below are a must have.

## Rule 1: Every statement must be cited

Every factual or definitional statement must carry a citation to a verifiable source. If you cannot cite it, do not write it.

This applies to:

- Definitions of terms
- Claims about how a pattern, practice, or technology behaves
- Trade-offs, benefits, and drawbacks

## Rule 2: Cite in APA 7 style

Use APA 7th edition for both in-text citations and the reference list.
See the [APA Style guide](https://apastyle.apa.org/style-grammar-guidelines/references/examples).
