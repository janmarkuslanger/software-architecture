# What is software architecture?

Software architecture has no fixed definition. There are several perspectives on software architecture. 

- Structure oriented
- Decision oriented
- Principle ortiented
- Pragmatic ortiented

## Principle ortiented

ISO/IEC/IEEE 42010:2022 defines software architecure as "fundamental concepts or properties of an entity in its environment and governing principles for the realization and evolution of this entity and its related life cycle processes".
