# What is software architecture?

Software architecture has no fixed definition. There are several perspectives on software architecture. 

- Structure oriented
- Decision oriented
- Principle oriented
- Pragmatic oriented

---

## Structure oriented

Bass, Clements and Kazman (2021) define software architecture as: 

"The software architecture of a system is the set of structures needed to reason about
the system. These structures comprise software elements, relations among them, and
properties of both."

This means that a software architecture is defined by its structures. 
A structur contains:
- elements
- relations
- properties of elements and relations

## Principle oriented

ISO/IEC/IEEE 42010:2022 (2022) defines architecture as "fundamental concepts or properties of an entity in its environment and governing principles for the realization and evolution of this entity and its related life cycle processes".
